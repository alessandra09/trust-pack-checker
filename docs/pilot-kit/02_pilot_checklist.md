# Pilot checklist (for Oleksandra)

Time budget: 1 to 2 hours per pilot. If it goes past 2 hours, stop and note why in the tracker.

1. **Receive** (5 min). Reply within one working day that the file arrived and give the delivery date (3 working days). Add a row to `08_pilot_tracker.xlsx` with status "received".
2. **Check redaction** (5 to 10 min). Search the file for names, emails, phone numbers, IBANs, prices and discounts. If you find personal data or commercial terms, stop: delete the file and ask the sender to redact and resend.
3. **Run the tool** (5 min). Open the live site, choose the mode (own DPA or questionnaire: company mode; vendor DPA and answers: vendor mode), add the file, run without AI.
4. **Review every result by hand** (30 to 60 min). For each finding open the quote and check it says what the status claims. Read the whole DPA once for anything the tool did not look for.
5. **Fix tool errors in the report** (10 min). If a result is wrong, correct it in the report and write the error in the tracker ("feedback" column) so it can become a test.
6. **Write the report** (20 to 30 min). Export the HTML report, then use `03_report_template.md` for the summary at the top. Keep the disclaimer.
7. **Send** (5 min). Email the report as an attachment or PDF. Ask for the 15-minute feedback call and propose two times.
8. **Delete the file** (2 min). Delete the received document from email, downloads and any copies. Note the deletion date in the tracker.
9. **Log it** (5 min). Fill in hours spent, result summary and the follow-up date (day 3 and day 7, see `05_followup_messages.md`).
