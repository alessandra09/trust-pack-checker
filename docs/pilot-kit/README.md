# Pilot kit

Copy-paste material for running free pilot reviews. English only; every claim here is also on the site.

| File                      | Use                                                                   |
| ------------------------- | --------------------------------------------------------------------- |
| 01_reply_to_interested.md | Reply when someone wants the pilot                                    |
| 02_pilot_checklist.md     | Your step-by-step for one pilot (1 to 2 hours)                        |
| 03_report_template.md     | Structure of the report you send                                      |
| 04_feedback_questions.md  | The 15-minute feedback call                                           |
| 05_followup_messages.md   | Day 3 and day 7 follow-ups                                            |
| 06_consultant_outreach.md | First message to a DPO consultant                                     |
| 07_founder_outreach.md    | First message to a B2B SaaS founder                                   |
| 08_pilot_tracker.xlsx     | Tracker with dropdowns and a Summary sheet; delete the 3 EXAMPLE rows |
| 09_one_pager.html / .pdf  | One-page leaflet for consultants                                      |

Regenerate the tracker with `npx tsx scripts/pilot-kit/make-tracker.ts`, and the one-pager with `npx tsx scripts/pilot-kit/make-one-pager.ts` while `npx vite preview --port 4173` runs.
