# Privacy

- Your documents stay in the browser tab's memory. Nothing is uploaded to a server; there is no backend, no account, no analytics.
- Without AI, no network request leaves the page.
- With AI enabled (after an explicit consent step), only the question text and a few selected passages are sent to Anthropic using your own API key. Whole files and file names are never sent.
- Your API key is kept in memory. It is saved in this browser only if you tick "remember on this device".
- A strict Content-Security-Policy allows network connections only to the app itself and `https://api.anthropic.com`.
